# Obrativa · app publicado

Este repositório contém só o app pronto (gerado pelo build), publicado pelo
GitHub Pages em https://eagleaiagency.github.io/obrativa.github.io/

O código-fonte fica fora daqui. Para atualizar: na pasta do código, rode
`npm run publicar` (gera o build e copia para esta pasta) e faça commit e push.

Arquivos:
- `index.html`: o app inteiro num arquivo só
- `manifest.webmanifest`, `icones/`: atalho com o ícone da Obrativa
- `sw.js`: permite instalar e abrir sem internet
